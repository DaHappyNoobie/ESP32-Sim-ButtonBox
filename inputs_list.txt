List of button box inputs
-------------------------

Total : 
3-9 Momentary switches
3-8 Toggle switches
1-17 Buttons
-----> If using 9 momentaries, 8 toggles, 1 button -> 27 GPIOs
-----> At least 1 GPIO Expander (16bit) should be used

TRIMMING
--------
Elevator Trim +/- -> Momentary switch
Aileron Trim +/- -> Momentary switch
Rudder Trim +/- -> Momentary switch

ENGINE CONTROL
--------------
Engine Select 1 On/Off -> Toggle switch (small)
Engine Select 2 On/Off -> Toggle switch (small)
Engine Select 3 On/Off -> Toggle switch (small)
?? Apply Engine Select // Ignition ? -> Pushbutton
Propeller Pitch +/- -> Momentary switch or 2 buttons
Fuel Mixture +/- -> Momentary switch or 2 buttons
Oil Radiator +/- -> Momentary switch or 2 buttons
Water Radiator +/- -> Momentary switch or 2 buttons
?? Cowling Shutters +/- -> Momentary switch or 2 buttons
Supercharger Gear +/- -> Momentary switch or 2 buttons

GEAR AND LIGHTS
---------------
Landing Gear Up/Down -> Toggle switch
Tail Wheel Lock/Unlock -> Toggle switch or single button
Landing Lights toggle -> Toggle switch or single button
Navigation Lights toggle -> Toggle switch or single button
Formation Lights toggle -> Toggle switch or single button
